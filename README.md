# Wallet App

Sistema personal para administrar finanzas mediante bolsillos virtuales.

## Objetivo inicial

Controlar de forma independiente los fondos destinados a:

- Ahorro.
- Uso diario.

Los balances se calcularán a partir de los movimientos registrados en el sistema.

## Aplicaciones

- API REST desarrollada con Laravel.
- Aplicación web desarrollada con React y TypeScript.
- Aplicación móvil desarrollada con React Native y Expo.
- Base de datos PostgreSQL.
- Infraestructura contenerizada con Docker Compose.
- Acceso privado mediante Tailscale.

## Estado del proyecto

Proyecto en etapa de planificación e inicialización.

## Módulos funcionales previstos

1. Identidad y autenticación.
2. Bolsillos virtuales.
3. Libro de movimientos.
4. Balances.
5. Transferencias internas.
6. Reportes.
